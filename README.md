# Dinnrm — 个人设计作品集

丁若木的个人网站，使用 React 18、Vite 6 和自定义 CSS，托管在 GitHub Pages。

- 网站：https://dinnrm.github.io/
- 仓库：https://github.com/Dinnrm/Dinnrm.github.io

## 本地开发

使用 Node.js 22（与部署环境一致）：

```bash
npm ci
npm run dev
```

生产构建与预览：

```bash
npm run build
npm run preview
```

## 页面与设计

电脑端采用独立栏目视图，一次只显示一个栏目；手机和 iPad 保留连续浏览的六个区块。导航与长页内容使用同一顺序：主页、教育、获奖、设计、摄影、联系。原项目与设计已合并为“设计作品”，保留分类按钮，并按最新说明展示九项作品。链接使用 `#/home`、`#/education` 等形式，也兼容原有 `#education` 等链接；旧项目链接 `#/projects`、`#projects` 转到 `#/works`，支持刷新及浏览器前进、后退。

长页导航在菜单关闭、布局提交后的下一帧定位栏目标题，按实际固定导航高度加 14px 留白计算偏移，下一帧再校准一次。重复点击同一栏目仍会定位；联系区块至少占一屏，确保末尾标题也能对齐。触摸和鼠标打开菜单不自动转移焦点，键盘打开保留首项焦点；忽略空的失焦目标，避免 Safari 在链接点击前关闭菜单。刷新及前进后退由栏目链接管理位置，避免原生滚动恢复覆盖目标。

视觉采用暖白底色、深色文字、朱红强调色，以及统一的系统无衬线字体。电脑端使用圆角表面、轻微位移淡入、滑动导航选中背景和按压反馈。包含手机导航、设计分类筛选、中英文切换和深浅色模式。主题默认跟随系统，手动选择与语言偏好会保存在浏览器内；支持跨标签页同步、键盘焦点和减少动态效果偏好。

独立栏目仅在宽度至少 1100px、支持精细指针和悬停、且没有触控能力的环境启用。触控设备继续使用长页，包括接入触控板或使用桌面网站模式的 iPad；窄电脑窗口也使用长页。动效以 CSS 的透明度与位移为主，连续长页不会整体参与切页动画。

## 文件与内容维护

```text
src/
├── App.jsx                  # 页面容器、导航和分类筛选状态
├── components/
│   ├── PortfolioPage.jsx    # 六个栏目及保留的内容
│   ├── DesignCollection.jsx # 作品封面卡片与分类
│   ├── ProjectDetail.jsx    # 独立作品详情页
│   └── Icon.jsx             # 共享图标
├── styles.css               # 主题变量、排版和响应式布局
├── hooks/
│   ├── usePreferences.js    # 主题、语言和偏好同步
│   ├── useImageProtection.js # 所有当前及后续图片的操作限制
│   └── usePageNavigation.js # 响应式页面模式、链接和滚动定位
├── data/
│   ├── content.js           # 个人介绍、奖项、双语作品与分类
│   ├── projectImages.js     # 真实海报及响应式展示副本
│   ├── works.js             # 原有作品分类说明
│   └── translations.js     # 中英文界面与英文内容对应文本
└── assets/
    ├── portrait.png         # 原始肖像仅留本地，不再跟踪
    ├── portrait-800.jpg     # 页面展示副本，600 × 800
    └── portrait-1400.jpg    # 高清展示副本，1050 × 1400
```

`src/components/` 中除上述四个组件外还保留了未启用的早期实现；当前发布入口是 `src/main.jsx` → `src/App.jsx` → `PortfolioPage.jsx`。修改页面请以当前入口为准。

原有介绍、奖项、项目和肖像均保留；按用户要求删除项目说明中的“已落地”、获奖行开头的级别标签及页脚返回主页、源码链接。主页移除顶部专业标签和底部导览行，常用软件位于作品按钮上方。教育页使用两张学历卡片与官方校徽，校园图片已移除，素材原始文件仅在本地保留于 `src/assets/school/originals/`。来源记录见该目录 `SOURCES.md`。

获奖电脑双栏按左栏从上到下、再右栏从上到下阅读，手机与平板仍为单列。设计分类依据 `content.js` 的 `categories` 筛选：全部 9 项、海报 2 项、主视觉 3 项、品牌 3 项、书籍 1 项、其他 1 项；跨类别作品同时出现在相应筛选结果中。两组海报包含 7 张真实图片，另七项按已提供的名称和说明展示。摄影仍为分类索引。`hello@example.com` 仍是原有示例邮箱，页面标注待更新。

作品的稳定 ID、类别与中英文内容统一维护于 `content.js`，图片映射位于 `projectImages.js`，界面文字位于 `translations.js`。分类使用稳定 ID，不依赖数组位置。

## 发布

`.github/workflows/deploy.yml` 在推送到 `main` 时执行 `npm ci`、`npm run build`，并发布 `dist/`。Vite 使用根路径 `/`，符合此 GitHub Pages 用户站的部署方式。

本次改版在 `codex/portfolio-redesign` 分支完成，最新手机导航修复已获用户上线授权，通过 `main` 的原有自动发布流程更新。实际构建与部署结果可在仓库 Actions 中查看。

## 2026-10-06 作品补齐与图片限制

`DesignCollection.jsx` 展示完整海报与说明，不提供单独点击放大、高清链接或下载按钮。新海报只发布 320px／960px WebP 展示版，完整原始文件留在用户提供的本地文件夹。图片来源与转换记录见 `src/assets/projects/SOURCES.md`。

`useImageProtection.js` 通过文档级捕获事件统一限制图片点击、右键与拖拽；CSS 限制拖动、选择和触摸菜单，现有图片声明 `draggable="false"`。事件委托也覆盖以后新增的图片；不要另行增加图片链接、放大或下载入口。

公开网页无法防止截图或浏览器提取。原始肖像及学校原始图片已取消当前 Git 跟踪并加入忽略规则，本地文件未删除；此前公开 Git 历史中的副本仍可能访问，此次未重写历史。
